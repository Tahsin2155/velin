Guide

Velin is a start page: a blank canvas where you drop widgets, place text, and set your own background. This page covers getting it onto your new tab, and then how to use it.

Three ways to use Velin

Velin's own extension Another extension or browser setting Just the website
What it does Velin becomes your new tab, loaded from files on your computer. Your new tab redirects to Velin's web address. You open Velin in a tab when you want it.
Browsers Chrome, Edge, Brave (Chromium). Chromium browsers, Firefox, Safari. Any modern browser.
Setup Load unpacked, in developer mode (about a minute). Install a small third-party extension, or change a browser setting. None.
Trade-off Not on the Web Store yet, so your browser may show a developer-mode notice. The page is fetched from the website, so it normally needs a connection. You're trusting a third-party extension too. Not on your new tab.

Whichever you pick, your data is stored in your browser and never sent to a server. The three options don't share storage with each other, though — see backup and moving data.

Velin's own extension

This is the simplest route if you use Chrome, Edge or Brave. The steps are on the install section of the home page: download the zip, unzip it somewhere permanent, turn on Developer mode on your extensions page, choose Load unpacked, and pick the folder.

Updating: download the new zip, replace the files in the same folder, then press the reload icon on Velin's card on the extensions page. Your data stays.

Using Velin without its own extension

You don't need Velin's extension to have Velin on your new tab. The web version lives at this address:

https://tahsin2155.github.io/velin/app

Use that address with one of the options below. Data you create this way is stored by the website, so it is separate from the extension's data.

Chrome, Edge, Brave and Vivaldi

These browsers can't set a custom new-tab address in their settings, but a "new tab redirect" extension can.

  1. Open your browser's extension store (Chrome Web Store; Edge also has its own add-ons store) and search for new tab redirect or custom new tab URL.
  2. Install one, then open its options.
  3. Paste the Velin address above. Use the full address, starting with https:// — some redirect extensions don't accept it without.
  4. Open a new tab.

Choose carefully. A new-tab extension sees every new tab you open. Read the permissions and privacy details before installing, and prefer a small one that asks for little. Redirect extensions generally also can't control where the keyboard cursor lands, so the address bar may not be focused on a new tab.

Firefox

Firefox's settings let you choose a custom page for the homepage and new windows (Settings → Home → Homepage and new windows → Custom URLs), but for new tabs you can only pick Firefox Home or a blank page. To get Velin on every new tab you need a new-tab add-on from addons.mozilla.org (search for new tab override or custom new tab URL) and the same address as above. Setting Velin as the homepage works without any add-on.

Safari on Mac

Safari can do this by itself. Open Safari → Settings (older versions call it Preferences), go to General, set the Homepage to the Velin address, and choose Homepage for new tabs (and new windows, if you want).

Any browser: keep it a click away

Bookmark the address, or set it as your startup page (in Chrome, Settings → On startup → Open a specific page). You won't get it on every new tab, but it's always one click away.

Using Velin

Everything saves automatically to your browser's IndexedDB — there is no save button.

Quick start

  1. Open a new tab (or the web version).
  2. Click ✦ view at the top to switch to edit mode. That unlocks dragging, resizing and adding widgets.
  3. Use the toolbar at the bottom to add widgets, change the background, or place text.
  4. Switch back to view mode when you're done, so nothing moves by accident.

View mode and edit mode

view (✦) Widgets are locked in place. The safe default for everyday use.
edit (✎) Widgets can be dragged, resized and deleted, and free text can be placed.

Click the mode button, or press E (it doesn't trigger while you're typing in a text field).

Widgets

Add widgets from the toolbar: ⊕ clock, ⊕ bookmarks, ⊕ todo, ⊕ note, ⊕ pomodoro. In edit mode, drag a widget by its header and resize it from the bottom-right corner. Click ✕ in the header to remove it.

Clock

Click the clock face to switch between digital and analog. It shows the time and date and updates live.

Bookmarks

Add a bookmark with a name and a URL. Velin looks up the site's icon, and falls back to a letter if it can't find one. Only http:// and https:// addresses are accepted.

Todo

Type a task and press Enter or click add. Tick the checkbox to mark it done and click × to delete it. The ✓× button in the header clears all completed tasks at once.

Note

A small markdown editor with a live preview. Toolbar shortcuts: B bold, I italic, ` code, H1/H2 headings, — divider, • bullet list. Click preview to see it rendered and edit to go back to the text. In view mode a note always shows the rendered version. ⌫ in the header clears the note.

Markdown that works: headings, bold, italic, inline code, fenced code blocks, links, bullet and numbered lists, task lists, quotes, horizontal rules and tables.

Pomodoro

A focus timer: 25 minutes of focus, a 5-minute short break, and a 15-minute long break every fourth session. Use start and reset, and click the mode labels to jump straight to a break. When a session ends Velin can show a notification — allow notifications if your browser asks. If you have Velin open in several tabs, the timer stays in sync between them.

Free-floating text

Click ✏ text in the toolbar (edit mode only), then click anywhere on the canvas to drop a text box. Click into a box to select it; a small style bar appears with A−/A+ for size, ↺/↻ to rotate, B for bold, a colour swatch, and ✕ to delete. Press Esc to leave text-placement mode.

Background, themes and blur

Background

Click ◑ bg to open the background panel. It has three tabs:

  • Solid — preset swatches or a custom colour.
  • Gradient — a preset, or your own from/to colours and direction.
  • Image — upload your own (up to 8 MB), with brightness (0–200%) and blur (0–20 px) sliders. Only one background image is kept at a time; uploading a new one replaces the old.

Themes

The four dots in the toolbar switch the overall look: dark, light, glass, and black & white.

Backdrop blur

The ◈ blur button cycles through auto (Velin guesses from your device whether blur is affordable), on, and off. If Velin feels slow on an older machine, try off.

Backup and moving data

  • ⬇ export downloads one JSON file with your whole setup: theme, background, widgets, notes and bookmarks.
  • ⬆ import loads such a file. It replaces your current setup, so export first if you want to keep what's there.

Because Velin's extension, the web version, and each browser keep their own storage, export/import is how you move between them: export in the old place, import in the new one. Do this before removing the extension or clearing your browser's site data, both of which erase Velin's data.

Keyboard shortcuts

E Toggle view/edit mode
Enter Confirm a new todo item or bookmark while typing in those fields
Esc Leave free-text placement mode

Troubleshooting

My new tab still shows the browser's default page

Check that Velin is switched on at your extensions page. Only one extension can control the new tab at a time, so if you have another new-tab extension, turn it off.

My widgets or notes are gone

Velin stores data per place: the extension, the website, and each browser are separate. Removing the extension or clearing site data also erases it. If you set Velin up in one place and opened it in another, you're looking at an empty copy — import an export file to bring your setup across.

I don't get a notification when the Pomodoro ends

Notifications are optional and need your permission. Allow them when the browser asks, or check the notification permission for the page in your browser's site settings.

Velin feels slow

Set ◈ blur to off and use a smaller background image.
