a new-tab start page

A new tab that's yours.

Velin is a start page for your browser. Add widgets, write markdown notes, pin bookmarks, pick a background. It all saves in your browser — no account, no sync server.

Get the extension Try it in the browser

Free to use, with the source on GitHub. The extension works in Chrome, Edge and Brave and isn't on the Web Store yet, so it installs in developer mode — steps below. Another browser, or another extension? See the guide.

What's in it

Widgets you arrange yourself

Clock, bookmarks, todo, notes and a pomodoro timer. Drag a widget by its header, resize it from the corner, and it stays where you left it. The pomodoro keeps running across tabs.

Markdown notes

A note widget is a small markdown editor with a live preview: headings, bold and italic, code, links, lists and tables.

Your own background

Solid colors, gradients, or an image of your own, with brightness and blur sliders.

  • View and edit modes Press E to lock everything in place, or unlock it to rearrange.
  • Free-floating text Place text anywhere on the canvas.
  • Export and import Save everything to one JSON file and load it back anywhere.
  • No build step Four files. Open app.html and it works.

Everything stays in your browser

Widgets, notes, bookmarks and background images are stored in your browser's IndexedDB. There's no account and no Velin server.

Two things do reach the network: fonts load from Google Fonts, and bookmark icons are looked up through DuckDuckGo's icon service (then the site's own favicon as a fallback).

Install the extension

For Chrome, Edge and Brave. Velin isn't on the Web Store yet, so you load it yourself — it takes about a minute.

  1. Download and unzip. Get velin-extension.zip and unzip it somewhere permanent. The browser loads Velin from that folder, so don't delete it.
  2. Open your browser's extensions page. Browsers block links to it, so copy the address and paste it in a new tab.
  3. Turn on Developer mode (the switch at the top right).
  4. Click Load unpacked and choose the unzipped folder.
  5. Open a new tab. That's Velin.

Developer-mode warning. Because it's loaded this way, your browser may show a notice about developer-mode extensions. That's expected until Velin is on the Web Store.

Your data is separate from the website. The extension and the web version keep their own storage. To move your setup between them, use ⬇ export in one and ⬆ import in the other.

Updating. Download the new zip, replace the files in the same folder, then press the reload icon on Velin's card in the extensions page. Your data stays.

Removing. Removing the extension deletes its data, so export first.

Firefox. Not supported as an extension yet. The web version works there.

Not on Chrome, Edge or Brave, or you'd rather use a different extension? You can still get Velin on every new tab — see using Velin without its own extension.
